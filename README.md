<details>
<summary><b>Explore the AI workflow and voice integration</b></summary>

<br/>

**Problem**

Users encounter messages and claims that may be misleading, suspicious, or designed to deceive.

**Solution**

SentinelVoice AI is an AI application designed to analyze potentially misleading or scam-related content and help users examine it more carefully.

**Key Features**

- AI-assisted content analysis.
- Integration with the Google Gemini API.
- Voice AI capabilities using Murf AI.
- Interactive Gradio interface.
- Web-based access through Hugging Face Spaces.

| Attribute | Details |
|:---|:---|
| Stack | Python, Google Gemini API, Murf AI, Gradio |
| Scale | Project-stage AI application |
| Performance | No formal latency or accuracy benchmark published |
| Security | API-key handling and user-input validation should be reviewed before production use |
| Impact | Aims to help users assess potentially suspicious content |
| Repository | [SentinelVoice AI](https://github.com/bhargavramanamarchi/sentinel-voice-ai-murf-ai) |

**Engineering Focus**

This project explores integrating an LLM with a user interface and voice-related functionality. AI-generated assessments should be treated as assistance rather than definitive proof that content is true, false, or fraudulent.

**Repository:** [View Source Code](https://github.com/bhargavramanamarchi/sentinel-voice-ai-murf-ai)

</details>

### 03. Resume AI — AI-Powered Resume Analyzer

<details>
<summary><b>Explore resume analysis and job-description matching</b></summary>

<br/>

**Problem**

Applicants need a practical way to compare their resumes with job descriptions and identify areas that may require improvement.

**Solution**

Resume AI is a web application that analyzes a resume PDF against a job description using an LLM API.

**Key Features**

- Resume PDF processing.
- Job-description-based analysis.
- AI-generated feedback.
- Flask application backend.
- Web deployment using Render.

| Attribute | Details |
|:---|:---|
| Stack | Python, Flask, Google Gemini API, HTML |
| Scale | Project-stage web application |
| Performance | No formal performance benchmark published |
| Security | Uploaded-file handling and API-key configuration should be reviewed for production |
| Impact | Aims to help applicants evaluate resume relevance |
| Repository | [Resume AI](https://github.com/bhargavramanamarchi/resume-ai-project) |

**Engineering Focus**

The project explores file processing, backend routes, API integration, and the use of an LLM to generate context-specific feedback.

**Repository:** [View Source Code](https://github.com/bhargavramanamarchi/resume-ai-project)

</details>
